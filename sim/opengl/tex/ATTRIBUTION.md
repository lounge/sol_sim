originals below. IAU north is the top row; the prime meridian is at u = 0.5.

## Steve Albers, Planetary Maps — personal, non-commercial use only

Source: https://stevealbers.net/albers/sos/sos.html. The page states:
"The images on this page are intended for personal non-commercial use only."
Underlying data are NASA spacecraft images (Voyager, Galileo, Cassini, Juno,
New Horizons) processed by the credited authors.

- io — Voyager + Galileo mosaic (Albers)
- europa — Voyager/Galileo (Björn Jónsson, John van Vliet) + Juno PJ45 (Albers)
- ganymede — Björn Jónsson, modified with USGS data (Albers)
- titan — Ian Regan / USGS, Cassini ISS (2018)
- rhea — Cassini reprojection over USGS Voyager base (Albers)
- iapetus — Cassini reprojection over USGS Voyager base (Albers)
- miranda — William Johnston / USGS Voyager data
- titania — Ted Stryk Voyager images over USGS positional base (Albers)
- oberon — Ted Stryk Voyager images over USGS positional base (Albers)
- triton — JPL Voyager mosaic + William Johnston / A. Tayfun Oner colour (Albers)
- charon — New Horizons map and colour images (Albers)
